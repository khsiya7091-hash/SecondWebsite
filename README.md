# SecondWebsite

A simple employee onboarding system for a company with up to 40 employees.

## Features
- First sign-up page with:
  - Company name
  - Name
  - Surname
  - Bank details
  - Directory names and surnames
- Employee registering page with:
  - Name
  - Surname
  - ID number
  - Address
  - Position
- Employee question page with:
  - Name
  - Surname
  - Position in company
  - Confirmation check against employee registering details
- Automatic employee number generation starting from `1001`
- Live list of registered employees and count out of 40

## Run
From the project folder, open `index.html` in a browser.
